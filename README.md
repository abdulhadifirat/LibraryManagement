(English)
LibraryManagement
This project is a C# and .NET based multi-layered architecture Library Management System. The goal is to manage books, users, and borrowing operations in a structured way.
🚀 Features
- Layered architecture: Business, Core, DataAccess, Entities, WebApi
- Add, delete, update books
- User management
- Borrowing and returning operations
- RESTful API support
🔧 Installation
git clone https://github.com/abdulhadifirat/LibraryManagement.git
cd LibraryManagement
- Open with Visual Studio or Rider
- Run LibraryManagement.sln solution file
- Install required NuGet packages
📖 Usage
- Manage books and users via WebApi endpoints.
- CRUD operations enable full library management.
🛠️ Technologies
- C#
- .NET Framework / .NET Core
- Entity Framework
